# Minecraft Interactive Map

## Локальный запуск

1. Открой эту папку в VS Code.
2. Запусти локальный сервер из корня проекта (например, расширением Live Server) и открой `index.html`.
3. В `tiles.json` уже внесены все 12 PNG из папки `map/`.

## Обновление каталога после добавления PNG

В терминале VS Code из корневой папки проекта выполни:

```bash
npm run build
```

Скрипт `scripts/generate-tiles.js` рекурсивно сканирует `map/` и пересоздаёт `tiles.json`. Для имён формата `0_0_x-2048_z-1536.png` он считывает индексы сетки и координаты `x`/`z`.

Для Cloudflare Pages укажи:
- Build command: `npm run build`
- Build output directory: `/` (корень проекта)

Не загружай папку `.git` в архив сайта. Для обновления опубликованного сайта отправь изменения в подключённый Git-репозиторий либо заново загрузи обновлённые файлы в Pages.
